# 一、项目概述

## 1.1 赛题背景

台风是影响我国沿海地区最重要的气象灾害之一，其路径、强度和降水分布具有高度的复杂性和不确定性。准确预测台风的路径演变、强度变化及降水时空分布，对于防灾减灾具有重要意义。

本赛题要求基于历史台风最佳路径数据（CMABSTdata）和GPM卫星降水遥感影像（GPM_3IMERGHHE.07），建立数学模型，揭示台风"路径—强度—环境—降水"的内在关联机制，并实现对特定台风降水时空分布的预测。

## 1.2 研究目标

| 问题 | 核心任务 | 输出成果 |
|------|----------|----------|
| Q1 | 分析台风路径、强度与降水特征的定量关系 | 特征相关性矩阵、重要性排序、可视化图表 |
| Q2 | 预测KONG-REY和MAN-YI两场台风的降水时空分布 | 降水空间分布图、时空演化序列 |
| Q3 | 构造虚拟台风情景，分析极端降水趋势 | 敏感性分析结果、未来趋势推断 |

# 二、数据源与处理流程

## 2.1 原始数据介绍

### 2.1.1 台风最佳路径数据 (CMABSTdata/)

**数据来源**：中国气象局最佳路径数据集

**文件格式**：TXT文本文件，按年份组织（2014-2025）

**数据结构**：
```
头记录格式：66666 年月日时 强度 纬度(0.1°) 经度(0.1°) 气压 风速 ...
数据记录格式：时间 强度 纬度(0.1°) 经度(0.1°) 气压(hPa) 风速(m/s)
```

**时间分辨率**：原始为6小时间隔，通过三次样条插值提升至0.5小时

### 2.1.2 降水遥感影像数据 (TIFdata/)

**数据来源**：GPM_3IMERGHHE.07 (全球降水测量卫星)

**文件格式**：GeoTIFF栅格影像

**组织结构**：
```
TIFdata/
├── 2014070/           # 事件编号
│   ├── 3B-HHR-E.MS.MRG.3IMERG.20140717-S000000-E002959.0000.V07B_*.tif
│   ├── 3B-HHR-E.MS.MRG.3IMERG.20140717-S003000-E005959.0030.V07B_*.tif
│   └── ...
├── 2024020/
│   └── ...
└── ...
```

**空间分辨率**：约0.1°（~10km网格）

**时间分辨率**：30分钟

**数据范围**：以台风中心为基准的矩形区域

## 2.2 数据处理流水线

### Step 1.1: 台风轨迹数据解析与插值

**脚本文件**：`step1.1 data process.py`

**核心功能**：
1. 解析CMA最佳路径TXT文件
2. 三次样条插值将时间分辨率从6h提升至0.5h
3. 计算运动学特征

**关键数学公式**：

**(1) Haversine大圆距离公式**
```
d = 2R × arcsin(√[sin²((lat₂-lat₁)/2) + cos(lat₁)×cos(lat₂)×sin²((lon₂-lon₁)/2)])

其中：R = 6371 km (地球平均半径)
```

**(2) 移动方位角计算**
```
θ = atan2(sin(Δlon)×cos(lat₂), cos(lat₁)×sin(lat₂) - sin(lat₁)×cos(lat₂)×cos(Δlon))
结果转换至 [0°, 360°] 范围，正北为0°
```

**(3) 路径曲率计算**
```
κ = Δθ / d

其中：Δθ 为相邻时段方位角变化（处理360°跨越问题）
      d 为移动距离
```

**(4) 最大风速半径估计 (Willoughby 2006经验公式)**
```
R_max = 46.4 × exp(-0.0155 × V_max + 0.0169 × |lat|)

其中：V_max 为最大风速 (m/s)
      lat 为纬度 (°)
```

**输出特征**：

| 特征名 | 含义 | 单位 | 计算方法 |
|--------|------|------|----------|
| Typhoon_ID | 台风编号 | - | 从头记录提取 |
| Time | 时刻 | datetime | 插值生成 |
| Lat | 纬度 | °N | 三次样条插值 |
| Lon | 经度 | °E | 三次样条插值 |
| Pressure | 中心气压 | hPa | 三次样条插值 |
| Wind_Speed | 最大风速 | m/s | 三次样条插值(截断至非负) |
| Distance_km | 时段移动距离 | km | Haversine公式 |
| Moving_Speed_kmh | 移动速度 | km/h | d / 0.5h |
| Moving_Direction | 移动方位角 | deg | 方位角计算 |
| Curvature_deg_per_km | 路径曲率 | deg/km | Δθ / d |
| Radius_max_wind_km | 最大风速半径 | km | Willoughby公式 |

### Step 1.2: TIF影像特征提取

**脚本文件**：`step1.2 tif process.py`

**核心功能**：
1. 批量读取TIF降水影像
2. 提取降水统计特征
3. 计算CMA标准降水梯度面积

**CMA降水强度分级标准**：

| 等级 | 名称 | 强度范围 (mm/h) | 特征名 |
|------|------|-----------------|--------|
| 1 | 小雨 | 0.1 - 2.0 | Area_Light_0.1_2 |
| 2 | 中雨 | 2.0 - 5.0 | Area_Moderate_2_5 |
| 3 | 大雨 | 5.0 - 10.0 | Area_Heavy_5_10 |
| 4 | 暴雨 | 10.0 - 20.0 | Area_Torrential_10_20 |
| 5 | 大暴雨/特大暴雨 | ≥ 20.0 | S_ext_Extreme_over_20 |

**降水质心计算公式**：
```
Centroid_Lat = Σ(lat_i × rain_i) / Σ(rain_i)
Centroid_Lon = Σ(lon_i × rain_i) / Σ(rain_i)

其中：lat_i, lon_i 为像素坐标
      rain_i 为该像素的降水强度
```

**像素面积等效**：每个像素约10km×10km = 100 km²

**输出特征**：

| 特征名 | 含义 | 单位 |
|--------|------|------|
| Folder_ID | 事件编号 | - |
| Time | 时刻 | datetime |
| Filename | 文件名 | - |
| P_total | 总降水量 | mm |
| P_max | 最大降水强度 | mm/h |
| P_Centroid_Lat | 降水质心纬度 | °N |
| P_Centroid_Lon | 降水质心经度 | °E |
| Area_Light_0.1_2 | 小雨面积 | km² |
| Area_Moderate_2_5 | 中雨面积 | km² |
| Area_Heavy_5_10 | 大雨面积 | km² |
| Area_Torrential_10_20 | 暴雨面积 | km² |
| S_ext_Extreme_over_20 | 极端降水面积 | km² |

### Step 1.3: 多模态数据融合

**脚本文件**：`step1.3 data integration.py`

**核心功能**：
1. 1D轨迹数据与2D降水数据时空对齐
2. 计算派生特征
3. 计算交叉特征
4. 预留外部环境变量接口

**时空对齐逻辑**：
```
匹配键：Typhoon_ID ↔ Match_ID (从Folder_ID提取)
时间键：Time ↔ Time (精确匹配)
匹配方式：Inner Join (仅保留同时存在的记录)
```

**派生特征计算**：

**(1) 6小时气压变化**
```
Delta_P_6h = P(t) - P(t-12)

说明：0.5h间隔，12个时段 = 6小时
按Typhoon_ID分组计算，防止跨台风差分
```

**(2) 6小时风速变化**
```
Delta_V_6h = V(t) - V(t-12)
```

**交叉特征计算**：

**(1) 降水中心偏移距离 (D_offset_km)**
```
D_offset = Haversine(lat_typhoon, lon_typhoon, lat_centroid, lon_centroid)

物理意义：降水质心相对于台风中心的偏离程度
反映降水分布的非对称性
```

**(2) 降水非对称性指数 (I_asy_Index)**
```
算法：
1. 以台风中心为原点划分四个象限
   - Q1(东北)：lon ≥ center_lon & lat ≥ center_lat
   - Q2(西北)：lon < center_lon & lat ≥ center_lat
   - Q3(西南)：lon < center_lon & lat < center_lat
   - Q4(东南)：lon ≥ center_lon & lat < center_lat

2. 计算各象限降水总量

3. 计算变异系数
   I_asy = std(Q1, Q2, Q3, Q4) / mean(Q1, Q2, Q3, Q4)

物理意义：CV值越大，降水空间分布越不均匀
```

**外部环境变量接口（待补充）**：

| 变量名 | 含义 | 数据源建议 | 计算逻辑 |
|--------|------|-----------|----------|
| LS_Land_Status | 海陆状态 | GSHHG海岸线数据 | 0=海洋, 1=陆地 |
| DTC_Dist_To_Coast_km | 距海岸线距离 | GSHHG海岸线数据 | 大圆距离计算 |
| DEM_Elevation_m | 地形高程 | SRTM/ETOPO1 | 栅格采样 |
| IEP_Potential_Energy | 强度演变势能 | ERA5 (SST, VWS) | 复合指数公式 |

### Step 1.4: 统计分析计算

**脚本文件**：`step1.4 data analysis.py`

**核心功能**：
1. 全维度Spearman秩相关系数矩阵
2. 随机森林特征重要性
3. SHAP解释性分析

#### 模块A: Spearman相关性矩阵

**方法说明**：Spearman秩相关系数衡量变量间的单调关系，对非线性关系敏感

**公式**：
```
ρ = 1 - (6 × Σd_i²) / (n × (n² - 1))

其中：d_i 为第i个样本的秩次差
      n 为样本数
```

**优势**：
- 不假设线性关系
- 对异常值鲁棒
- 适合非线性物理过程

#### 模块B: 随机森林特征重要性

**方法说明**：基于Gini不纯度下降量衡量特征贡献

**配置参数**：
```python
RandomForestRegressor(
    n_estimators = 100,    # 决策树数量
    max_depth = 10,        # 最大深度
    random_state = 42,     # 随机种子
    n_jobs = -1           # 并行计算
)
```

**重要性计算**：
```
Importance(X) = Σ (Gini_before - Gini_after) for all splits on X

归一化：ΣImportance(X_i) = 1
```

#### 模块C: SHAP解释性分析

**方法说明**：基于博弈论的Shapley值，量化每个特征对单个预测的贡献

**公式**：
```
φ_i = Σ [|S|!(n-|S|-1)!/n!] × [f(S∪{i}) - f(S)]

其中：S 为特征子集
      f 为模型预测函数
      n 为特征总数
```

**针对目标变量**：S_ext_Extreme_over_20（极端降水面积）

**输出矩阵**：[n_samples, n_features] 的SHAP值矩阵

# 四、第二问(Q2)技术路线：ConvLSTM空间残差网络预测框架

## 4.1 核心设计理念

### 4.1.1 为什么采用ConvLSTM？

**降水数据的空间结构特性**：
- GPM降水数据是二维网格数据（约0.1°分辨率）
- 降水分布具有明显的空间连续性和局部相关性
- 传统LSTM将空间维度展平，丢失空间结构信息

**ConvLSTM的优势**：
- 将卷积操作融入LSTM单元，保留空间结构
- 同时捕捉空间和时间依赖关系
- 参数共享减少过拟合风险

### 4.1.2 为什么采用残差学习？

**预测系统偏差问题**：
- 深度网络容易产生系统性偏差
- 直接预测难以校正这种偏差

**残差学习的优势**：
- 网络学习预测偏差而非绝对值，降低学习难度
- 改善梯度流动，支持更深网络
- 多尺度特征融合更自然

### 4.1.3 物理约束的必要性

**降水物理特性**：
- 非负性：降水量 ≥ 0
- 空间连续性：相邻网格降水值相近
- 时序因果性：未来降水依赖当前状态

**约束实现方式**：
- 通过损失函数添加约束项
- 输出层使用非负激活函数

## 4.2 网络架构详细设计

### 4.2.1 ConvLSTM单元结构

**数学公式**：

```
输入门：   i_t = σ(W_{xi} * X_t + W_{hi} * H_{t-1} + b_i)
遗忘门：   f_t = σ(W_{xf} * X_t + W_{hf} * H_{t-1} + b_f)
候选状态： g_t = tanh(W_{xg} * X_t + W_{hg} * H_{t-1} + b_g)
单元状态： C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t
输出门：   o_t = σ(W_{xo} * X_t + W_{ho} * H_{t-1} + b_o)
隐藏状态： H_t = o_t ⊙ tanh(C_t)

其中 * 表示卷积操作，⊙ 表示Hadamard积
```

### 4.2.2 编码器设计

**架构**：
```
输入层：降水场序列 [batch, T, H, W, 1]
    │
    ▼
ConvLSTM Layer 1
    - filters: N₁ (可调，建议64)
    - kernel_size: k₁×k₁ (可调，建议3×3)
    - padding: same
    - return_sequences: True
    - Dropout: 0.2
    │
    ▼
ConvLSTM Layer 2
    - filters: N₂ (可调，建议128)
    - kernel_size: k₂×k₂ (可调，建议3×3)
    - padding: same
    - return_sequences: False
    - Dropout: 0.2
    │
    ▼
时空编码 z [batch, H, W, N₂]
```

### 4.2.3 残差学习模块

**设计思路**：
```
第一阶段预测：
    P_pred = Decoder(z)

残差计算：
    R = P_true - P_pred

残差网络：
    ΔP = Conv2D_block(R, z)

最终预测：
    P_final = P_pred + ΔP
```

**残差网络结构**：
```
输入：残差场 R + 编码 z
    │
    ▼
Conv2D (N₂ filters, 3×3) + ReLU
    │
    ▼
Conv2D (N₂/2 filters, 3×3) + ReLU
    │
    ▼
Conv2D (1 filter, 1×1) + ReLU (非负约束)
    │
    ▼
输出：残差修正 ΔP
```

### 4.2.4 多时效解码器

**条件解码设计**：
```
共享编码 z
    │
    ├─→ Decoder_6h(z)  → P_6h
    │
    ├─→ Decoder_12h(z) → P_12h
    │
    └─→ Decoder_24h(z) → P_24h

每个解码器结构：
    Conv2DTranspose (上采样)
    → Conv2D (特征精炼)
    → Conv2D (输出，非负激活)
```

### 4.2.5 物理约束模块

**约束类型**：

| 约束名称 | 数学表达 | 物理意义 |
|----------|----------|----------|
| 非负约束 | P ≥ 0 | 降水量非负 |
| 空间连续性 | ‖∇P‖² < threshold | 降水场平滑 |
| 时序一致性 | ‖P_{t+1} - P_t‖ < v_max | 变化率限制 |

## 4.3 损失函数设计

### 4.3.1 总损失函数

```
L_total = L_mse + λ₁·L_spatial + λ₂·L_temporal + λ₃·L_physics
```

### 4.3.2 各损失项定义

**(1) 主损失：均方误差**
```
L_mse = (1/N) Σ ‖P_pred - P_true‖²
```

**(2) 空间连续性损失**
```
L_spatial = (1/N) Σ (‖∇_x P_pred‖² + ‖∇_y P_pred‖²)

其中 ∇_x, ∇_y 为空间梯度算子
```

**(3) 时序一致性损失**
```
L_temporal = (1/N) Σ ‖P_{t+1} - P_t‖²

约束预测场的时间演化平滑性
```

**(4) 物理约束损失**
```
L_physics = (1/N) Σ max(0, -P_pred)²

惩罚负降水值
```

### 4.3.3 多时效联合损失

```
L_total = w_6h·L_6h + w_12h·L_12h + w_24h·L_24h

权重建议：
- w_6h = 1.0 (短期精度要求高)
- w_12h = 0.8
- w_24h = 0.6 (长期不确定性大)
```

## 4.4 训练策略

### 4.4.1 数据构造

**输入序列构造**：
```
对于时刻 t 的预测：
    输入序列 = [P_{t-T+1}, P_{t-T+2}, ..., P_t]
    
    其中 T 为回溯窗口长度（建议12-24个时间步，即6-12小时）
    
    每个时间步的输入：
    X_t = [降水场(H×W), 台风中心位置, 强度特征, 环境变量]
```

**数据归一化**：
```
P_norm = (P - P_min) / (P_max - P_min)

或使用标准化：
P_norm = (P - P_mean) / P_std
```

### 4.4.2 训练流程

```
1. 数据准备
   - 加载历史降水场序列
   - 构造输入-输出对
   - 划分训练/验证/测试集

2. 模型训练
   for epoch in range(N_epochs):
       for batch in dataloader:
           # 前向传播
           z = Encoder(X_batch)
           P_pred = Decoder(z)
           ΔP = ResidualNet(P_pred, z)
           P_final = P_pred + ΔP
           
           # 损失计算
           loss = L_total(P_final, P_true)
           
           # 反向传播
           loss.backward()
           optimizer.step()
           
       # 验证集评估
       val_loss = evaluate(val_loader)
       early_stopping_check(val_loss)

3. 模型保存
   - 保存最佳模型参数
   - 保存训练历史记录
```

### 4.4.3 超参数配置

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 学习率 | 1e-4 | Adam优化器 |
| 批大小 | 16-32 | 视GPU内存调整 |
| 回溯窗口 T | 12-24 | 时间步数 |
| N₁ (filters_1) | 64 | 可调 |
| N₂ (filters_2) | 128 | 可调 |
| kernel_size | 3×3 | 可调 |
| λ₁ (空间约束) | 0.1 | 可调 |
| λ₂ (时序约束) | 0.1 | 可调 |
| λ₃ (物理约束) | 1.0 | 可调 |

## 4.5 预测目标变量详细说明

### 4.5.1 降水场预测

**输出**：降水空间分布 P(H×W)

**评估指标**：
- 场均方根误差(RMSE)：√[(1/N)Σ(P_pred - P_true)²]
- 结构相似性指数(SSIM)：衡量空间结构相似度
- 降水面积误差：各级降水面积对比

### 4.5.2 多时效预测

**输出**：{P_6h, P_12h, P_24h}

**评估指标**：
- 各时效RMSE
- 时效间误差增长曲线
- 预测场演化动画

### 5.1.2 物理合理性约束

**路径偏移约束**：
```
1. 偏移量上限：基于历史台风路径变异性
   ΔLat_max = 3σ(历史同期路径Lat偏差)
   ΔLon_max = 3σ(历史同期路径Lon偏差)

3. 气候学约束：符合季节性转向规律
```

**强度变化约束**：
```
1. 最大强度上限：
   Wind_max = min(潜在最大强度, 物理极限)

   潜在最大强度可由Emanuel(1988)理论计算

2. 强度变化率约束：
   |dWind/dt| < 30 m/s/24h (经验最大加强率)

3. 登陆衰减规律：
   登陆后强度指数衰减，衰减率与地形有关
```


## C. ConvLSTM数学原理

### C.1 ConvLSTM单元详解

ConvLSTM（卷积长短期记忆网络）是将卷积操作融入LSTM的一种网络结构，专门用于处理时空序列数据。

**与传统LSTM的区别**：

| 特性 | 传统LSTM | ConvLSTM |
|------|----------|----------|
| 空间处理 | 展平为一维向量 | 保留二维空间结构 |
| 参数共享 | 无 | 卷积核参数共享 |
| 空间依赖 | 丢失 | 保留 |
| 适用数据 | 一维序列 | 时空网格数据 |

**ConvLSTM单元公式**：

```
输入门：   i_t = σ(W_{xi} * X_t + W_{hi} * H_{t-1} + W_{ci} ⊙ C_{t-1} + b_i)
遗忘门：   f_t = σ(W_{xf} * X_t + W_{hf} * H_{t-1} + W_{cf} ⊙ C_{t-1} + b_f)
候选状态： g_t = tanh(W_{xg} * X_t + W_{hg} * H_{t-1} + b_g)
单元状态： C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t
输出门：   o_t = σ(W_{xo} * X_t + W_{ho} * H_{t-1} + W_{co} ⊙ C_t + b_o)
隐藏状态： H_t = o_t ⊙ tanh(C_t)
```

其中：
- `*` 表示卷积操作
- `⊙` 表示Hadamard积（逐元素乘法）
- `σ` 表示sigmoid激活函数
- `tanh` 表示双曲正切激活函数

### C.2 为什么ConvLSTM适合降水预测

**空间连续性保留**：
- 降水场具有明显的空间连续性，相邻网格的降水值高度相关
- ConvLSTM通过卷积操作保留了这种空间邻域关系
- 传统LSTM展平操作破坏了空间拓扑结构

**参数效率**：
- 卷积操作实现参数共享，大幅减少参数量
- 对于H×W的网格，全连接需要O(H²W²)参数，卷积只需O(k²)参数
- 参数共享减少过拟合风险，提高泛化能力

**多尺度特征捕捉**：
- 通过堆叠多层ConvLSTM，可捕捉不同尺度的空间特征
- 浅层捕捉局部降水模式（如对流单体）
- 深层捕捉大尺度降水结构（如台风螺旋雨带）

### C.3 ConvLSTM实现要点

**输入数据格式**：
```
输入形状: [batch_size, time_steps, height, width, channels]

对于降水预测：
- batch_size: 批大小（建议16-32）
- time_steps: 时间步数（建议12-24，即6-12小时历史）
- height, width: 空间网格大小（如64×64）
- channels: 特征通道数（降水场为1，可加入其他特征）
```

**关键技术参数**：

| 参数 | 建议值 | 说明 |
|------|--------|------|
| kernel_size | 3×3 或 5×5 | 捕捉局部空间依赖 |
| filters | 64-256 | 特征图数量 |
| padding | 'same' | 保持空间尺寸不变 |
| return_sequences | True/False | 是否返回完整序列 |

**训练技巧**：
1. 使用Dropout防止过拟合（建议0.2-0.3）
2. 使用BatchNorm加速收敛
3. 梯度裁剪防止梯度爆炸（clip_norm=1.0）
4. 学习率衰减策略（ReduceLROnPlateau）

### C.4 与残差学习的结合

**残差学习的数学表达**：
```
设编码器输出为 z，初始预测为 P_pred = Decoder(z)

残差网络学习：
    ΔP = ResidualNet(P_pred, z)

最终预测：
    P_final = P_pred + ΔP
```

**优势分析**：
- 网络学习残差（偏差修正）比直接学习绝对值更容易
- 改善深层网络的梯度流动，避免梯度消失
- 允许恒等映射，支持更深的网络架构
